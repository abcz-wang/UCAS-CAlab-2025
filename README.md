# UCAS-CALab-2025

中国科学院大学 CALab 项目 — FPGA 箱号 13

---

## 项目说明

本项目是 CALab 2025 FPGA 实验系列的一部分，主要完成AXI相关任务（Task14、Task15、Task16 ）。

---

## 任务信息

### Task12
- 注意：CSR 指令运行在特权态。
- 执行 CSR 指令时，CRMD 的 PLV 位必须为 `00`，否则会触发 **指令特权级错例外**。
- 当前版本尚未实现该特性，需要在后续版本中完善。

### Task13
- `inst_rdcntid` 指令必须视为 CSR 特权指令，否则仿真无法通过。

### Task14
- 延迟为0x003F的时候，上板时不时卡住，仿真未发现问题，在task16，此问题消失
- 修改延迟的方法为修改soc_verify\soc_axi\rtl\CONFREG\confreg.v的`define RANDOM_SEED {7'b1010101,16'h00FF}中的00FF，板子上8个开关，每个开关对应上面两个指示灯，从前往后一共16个灯，每个灯亮表示这一位为1，全亮了就是0b1111111111111111，后六个灯亮就是0b0000000000111111（0x3F）

### Task16
- 详见注释，实现类sram接口和axi转接桥，可在随机延迟下运行

## 使用方法
-我生成了一个脚本 `run.sh`，可以直接生成作业提交的文件，详见run.sh的注释或下面用法

### 脚本用法

```bash
./run.sh <prj号> <上一个任务名> <当前任务名>
示例: ./run.sh 5 exp15 exp16
```
需要将该脚本放在任务文件夹下，如/exp13下
且要改目录
