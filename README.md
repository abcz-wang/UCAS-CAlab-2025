# UCAS-CALab-2025

中国科学院大学 CALab 项目 — FPGA 箱号 13

---

## 项目说明

本项目是 CALab 2025 FPGA 实验系列的一部分，主要完成中断与例外设计相关任务（Task12、Task13 ）。

---

## 任务信息

### Task12
- 注意：CSR 指令运行在特权态。
- 执行 CSR 指令时，CRMD 的 PLV 位必须为 `00`，否则会触发 **指令特权级错例外**。
- 当前版本尚未实现该特性，需要在后续版本中完善。

### Task13
- `inst_rdcntid` 指令必须视为 CSR 特权指令，否则仿真无法通过。
- 注：若以后加指令，务必要在ID阶段inst_valid信号处加入。若加入新例外，务必注意优先级要求！

---

## 使用方法
我生成了一个脚本 `run.sh`，可以直接生成作业提交的文件，详见run.sh的注释或下面用法

### 脚本用法

```bash
./run.sh <prj号> <上一个任务名> <当前任务名>
示例: ./run.sh 4 exp12 exp13
```
需要将该脚本放在任务文件夹下，如/exp13下
